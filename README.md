# F1 Race Summariser

An AI-powered web application that transforms Formula 1 race information into concise, easy-to-read summaries. Instead of reading lengthy race reports or watching full race replays, users can quickly understand the key events, strategies, and highlights from any Grand Prix.


## Overview

F1 Race Summariser leverages modern AI and web technologies to generate race summaries, highlight important moments, and provide fans with a faster way to stay updated on Formula 1 events.

Whether you're a casual fan or a dedicated follower of the sport, this application provides an efficient way to catch up on races within seconds.


## Features

- AI-generated Formula 1 race summaries
- Key race highlights and important moments
- Fast and concise race recaps
- Responsive and modern user interface
- Frontend and backend architecture
- Easy to deploy and extend
